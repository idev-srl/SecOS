# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

SECoS is a freestanding x86-64 (long mode) secure kernel written in C99 + NASM. It boots two ways from one binary: **UEFI** (primary, via an external bootloader) and **GRUB Multiboot2** (legacy). The security focus is memory isolation: W^X enforcement, NX, user/kernel separation, validated syscall boundaries, and guard-paged stacks.

Development is organized into milestones (M0–M7). `ROADMAP_SECoS.md` is the source of truth for the technical roadmap and includes a critical architectural-issues list worth reading before deep work (several of those issues — linker COMMON, `vmm_space_destroy`, kernel stack guard pages, scheduler context switch — have since been fixed in M1/M2/M6/M7). `docs/devlog/M0.md`–`M7.md` document each milestone.

**Current real state (HEAD):** M0–M50 done — Phase 4 (hardening, M44–M49) integrated on `integ/phase4`; M50 = phase A of the BKL removal (`docs/BKL_REMOVAL_PLAN.md`) (M38/M39 WiFi radio and a few items are partial — see each entry; open work in `TASKS.md`; next: Phase 5 isolated drivers, `docs/ROADMAP_TO_COMPLETE_OS.md`).
- **M7** (ring-3 + `SYS_YIELD` cooperative scheduling) works; demo gated behind `M7_RING3_DEMO`. See `docs/devlog/M7.md` for the four bugs it uncovered (notably: clear `EFLAGS.NT` before `iretq`; private `PML4[0]` PDPT per user space; ELF copy stride bug).
- **M8** (preemptive multitasking) works: trapframe `isr_timer` + quantum preemption (ring-3 only), kernel idle task, `SYS_EXIT`→zombie→reap, `vmm_space_destroy` frees the private PDPT, no PMM leak (verified N=4/N=6). Demo gated behind `M8_SCHED_DEMO`. Root-caused/fixed a heap bug along the way: `kfree` coalesced non-physically-contiguous free blocks, inflating a block across the gap between frames so a later `kmalloc` wrote over an unrelated live page table (invisible to physmap watches since the heap addresses blocks via the identity map). Fix in `mm/heap.c`: coalesce only when `current + HEADER + size == next`. See `docs/devlog/M8.md`.
- **M9** (real userland + mandatory ELF signing) done — tag `M9_STABLE`. In-kernel crypto (`crypto/`: SHA-256/512 + Ed25519 verify, KAT-tested at boot). **Every ELF must be signed to run**: `process_create_from_elf` calls `elf_signature_verify` (`mm/elf_sign.c`) and refuses unless valid, unless built `-DDEV_ALLOW_UNSIGNED` (the M7/M8 synthetic demos use this). Digest = SHA-256(whole file, 64 sig bytes zeroed); Ed25519 over the digest; QSIG note; embedded pubkey in `crypto/secos_pubkey.h`. Host tools in `tools/` (`secos-keygen`, `secos-sign`, `elf2h.py`); `make user-progs` builds+signs `user/hello.c` → `crypto/user_hello_elf.h`. The signed `hello` is loaded from the VFS, verified, run in ring-3 (prints via `SYS_WRITE` fd 1/2 → console+debugcon). See `docs/SIGNING.md`, `docs/devlog/M9.md`.
- **M10** (storage & persistence) done. virtio-blk driver (`drivers/pci.*`, `drivers/virtio_blk.*`: legacy/transitional PCI, single split virtqueue in a page-aligned static buffer — kernel is identity-mapped so virt==phys for DMA — polled, bounce-buffered) registers block device `vda`; `block_dev_t` gains `write()`. VFS goes single-root → **multi-mount** (`fs/vfs.c`): ramfs root `/`, disk FS at `/mnt`, longest-prefix routing. **FAT32, ext2 and ext4 read-write** through the VFS (`fs/fat32.c`, `fs/ext2.c` full rewrites): kernel-written files are host-readable (`mtools`/`debugfs`) and `e2fsck`-clean; ext4 is **no-journal v0** (image `mkfs.ext4 -O ^has_journal,^metadata_csum`; extents + 64-bit supported, JBD2/csum deferred). `SYS_SPAWN`/`SYS_WAIT` (8/9) + shell `run <path>`: the interactive shell runs as the **scheduler idle task** (one sched change: save idle context on preemption) so a spawned ring-3 program returns control to the shell on `SYS_EXIT`. Gate `M10_RUN_DEMO`: a signed ELF is written to disk, read back, verified and run in ring-3 (tampered copy refused). See `docs/devlog/M10.md`.
- **M11** (Driver Space for real) done. The driver privilege is now **rooted in the code signature**: the `.note.secos` manifest gains v2 fields (`proc_type`, `dev_id`, `dev_caps`; desc 24→40 bytes, `version` 2), covered by the Ed25519 signature. `process_create_from_elf` sets `proc_type` and, for a `PROC_TYPE_DRIVER` manifest, auto-binds the process to its device with the granted (device-intersected) capability subset. `SYS_DRIVER` now enforces `proc_type==DRIVER` (else `DRV_ERR_NOTDRV`) **and** the per-binding granted caps (a driver granted READ/WRITE/GET_INFO is refused MAP_MEM even on a device that supports it); every event mirrors to debugcon (`[DRV-AUDIT]`). `process_destroy` drops driver bindings first (fixed a latent stale-`process_t*` privilege leak). Demo gate `M11_DRIVER_DEMO` runs a signed user-space driver (`user/driver_demo`: mediated reg read/write round-trips, un-granted MAP_MEM refused) and a signed plain-user probe (`user/userprobe`: all `SYS_DRIVER` denied). **Gotcha found**: `mm/heap.c` reliably serves `kmalloc` only up to one frame (~4 KB) — `kmalloc` of a larger size can silently return an undersized block — so the demo loads the embedded **signed** ELF directly (still verified) rather than via the VFS; a buddy/multi-frame allocator is an M12 item. See `docs/devlog/M11.md`.
- **M12** (memory scalability + W^X hard gate + **higher-half kernel**) done. PMM now manages **all** RAM: the 512 MB `total_frames` clamp and the 128 MB per-region identity clamps are gone (frames above the identity window are reached via the physmap; a defensive 32 MB bitmap cap ≈ 1 TB RAM). `find_free_frame` skips full bitmap words from a rolling cursor; `pmm_alloc_contiguous`/`pmm_free_contiguous` back multi-frame allocations. The **heap** (`mm/heap.c`) now addresses memory through the physmap (`phys_to_virt`), `expand_heap` allocates enough contiguous frames for the request, and `kmalloc` returns NULL instead of a silently-undersized block — **fixes the M11 >4 KB gotcha** (the M11 demo loads from the VFS again). `vmm_map`/`vmm_map_in_space` add a **W^X hard gate** (reject RW-without-NX with `-5`); boot self-tests log `[WX] W+X mapping rejected` and `[HEAP] large kmalloc(64K) OK`; on `-m 2G` the PMM reports ~2045 MB free. **Higher-half**: the kernel is linked + runs at `KERNEL_VMA = 0xFFFFFFFF80000000` (`-mcmodel=kernel -fno-pic`). `linker.ld` keeps a low `.boot` section (Multiboot2 header + 32-bit setup + initial tables) and links the rest HIGH/loads LOW via `AT()`. `boot/boot.asm` builds page tables mapping BOTH low identity (0–512 MB) AND the high half, then jumps high (`long_mode_high`); the UEFI loader (`uefi/*`) loads segments at their LMA (`p_paddr`) and maps PML4[511]→high-half. `mm/vmm.c` kernel PML4 maps PML4[511]; `kvirt_to_phys` (`mm/vmm.h`) translates kernel/physmap VMAs → physical for the two symbol-as-physical spots (PMM bitmap frame math, virtio DMA `phys_of`). **The low identity map is deliberately kept** (virtio DMA + early frame access use it). Both `smoke.sh --mb2` and `--uefi` PASS. **Deferred**: full demand paging (`vmm_region` path dormant), W^X of the identity huge-page map. See `docs/devlog/M12.md`.
- **M13** (usability & policy enforcement) done. **Manifest `max_mem` enforcement** (headline): `process_create_from_elf` refuses a process whose mapped footprint exceeds its signed manifest's `max_mem` (0 = unlimited), with a leak-free teardown (`elf_unload_process` + `vmm_space_destroy`); the limit is signature-rooted. New syscalls: `SYS_GETTICKS` (10, uptime), `SYS_MSG_SEND` (11) / `SYS_MSG_RECV` (12) over **kernel IPC channels** (`kernel/ipc.c`: 4 ring-buffer channels, non-blocking, user pointers validated + bounce-buffered). libc gains `getticks`/`msg_send`/`msg_recv`. Two separately-spawned ring-3 programs communicate without fork/fd inheritance (the channel is kernel-owned). Shell `run <path>` (M10) is the first-class on-disk launcher. Demo gate `M13_DEMO`: a producer sends on channel 0 + reports its uptime, a consumer reads it; a signed program declaring `max_mem=4 KB` is refused at load. See `docs/devlog/M13.md`.
- **M14** (full demand paging) done. User pages are no longer eagerly mapped: `process_create_from_elf` pins a private copy of the (signature-verified) ELF image and registers **per-process VMAs** (`mm/vma.{c,h}`, embedded in `process_t`) — `VMA_TYPE_FILE` (lazy-copied from the pinned image) for ELF segments, `VMA_TYPE_ANON` (zero-fill) for the stack/BSS. `elf_load_image_lazy` (`mm/elf.c`) does the same security validation as the eager loader but touches no frame; pages materialize one at a time in `vmm_handle_page_fault` (`mm/vmm.c`) via `vma_fault_in` (frame filled through the physmap RW alias, so RX code pages fill without a W^X violation). Because `copy_from/to_user` dereferences user VAs directly, a not-yet-faulted **syscall buffer** faults in kernel mode on a user address and is handled too (the handler keys on address+VMA, not the U/S bit) — no `user_copy.c` change. Teardown is automatic: `vmm_space_destroy` already frees every present user leaf, so `mapped_pages` tracking is gone with no leak/double-free. The stack **guard** is now the absence of a VMA below it. Manifest `max_mem` (M13) is checked against the **reserved footprint** (sum of VMA sizes). Demo gate `M14_DEMAND_DEMO`: a signed `hello` shows `mapped at load=0` for a `0x9000` reserved footprint, then 2 pages fault in (`[PF] demand page`) as it runs. See `docs/devlog/M14.md`.
- **M15** (fault-driven process termination) done — first milestone of Phase F (`docs/ROADMAP_TO_COMPLETE_OS.md`). A ring-3 CPU fault now **kills only the offending process** and returns to the scheduler instead of halting the kernel. `vmm_handle_page_fault` returns `0`/`-1` (no longer halts); `exception_handler` (`kernel/panic.c`) decides from the saved `cs`: `(cs&3)==3` ⇒ ring-3 ⇒ `sched_kill_current(vector)` (`kernel/sched.c`, mirrors the SYS_EXIT path: ZOMBIE + `pick_user` + `switch_to`, reaped later — zero new teardown, no leak); ring-0 ⇒ real kernel bug ⇒ original panic+halt. `process_t` gains `exit_code` (0=normal, `128+vec`=killed, POSIX-style; seed for M16 `wait`). Demo gate `M15_KILL_DEMO`: signed `user/crashtest` does a wild NULL write → `[KILL] pid=…`, never prints its post-fault line, then a signed `hello` runs to prove the kernel survived. See `docs/devlog/M15.md`.
- **M16** (exec model) done. Ring-3 programs now receive **argv/env**: `process_create_from_elf_args` builds argc/argv/envp on the (demand-paged) user stack and passes them per System V (`rdi`/`rsi`/`rdx`) — `main(void)` programs ignore them, so `crt0.S` is unchanged. `SYS_SPAWN` takes `a1=char**` (copied in); libc `spawn(path, argv)`. **Blocking `SYS_WAIT`** returns the child's exit status: handled in `syscall_trap.c` (rewinds `rip` to re-run on wake), the exiting child's status is delivered into the blocked waiter (`sched_wake_waitpid`). `SYS_EXIT` now carries the user status into `exit_code`. Shell `run <path> [args…]` passes argv. libc `waitpid(pid)`. Demo `M16_EXEC_DEMO`. See `docs/devlog/M16.md`.
- **M17** (blocking primitives) done. Built on M16's block/wake core (`sched_block_current` + rip-rewind re-run): **`SYS_SLEEP`** (13) blocks until a tick deadline (woken by `sched_wake_sleepers` from the timer tick); **`SYS_MSG_RECV` blocks** on an empty IPC channel until a `SYS_MSG_SEND` wakes it (`sched_wake_chan`) — backward compatible (a pre-queued message returns without blocking, so M13's poll consumer is unchanged). libc `sleep_ticks`. Demo `M17_BLOCK_DEMO` proves the receiver actually reaches `PROC_BLOCKED` before the producer runs. **Pipes + TTY deferred** (need fork/signals — Phase G/L). See `docs/devlog/M17.md`.
- **M18** (dynamic memory, Phase G start) done. `mmap`/`munmap`/`mprotect`/`brk` syscalls (14–17) on the M14 VMA framework: `brk`/`sbrk` grow a single ANON heap VMA, anonymous `mmap` bump-allocates from a 12 GB arena, `mprotect` re-protects present PTEs (`vmm_protect_in_space`, `invlpg`). All **W^X-enforced** (W+X rejected at the syscall and the mapper) and bounded by the signed manifest `max_mem` at runtime (`process_t.mem_limit`). VMAs gain tombstones (`vma_remove`) + `VMA_MAX`→64. libc `malloc`/`free` (first-fit over `sbrk`) + `mmap`/`mprotect`/`sbrk`. Demo `M18_MEM_DEMO` (`user/m18_mem`): malloc/free/reuse, mmap rw, W+X refused, mprotect RO then a fatal write to the RO page (`[KILL]`, reusing M15). See `docs/devlog/M18.md`.
- **M19** (copy-on-write fork, Phase G) done. **PMM frame refcounts** (`mm/pmm.c`: dense `frame_refs[]` after the bitmap; `pmm_share_frame`/`pmm_unref_frame`; leaf frees in `vmm_unmap_in_space`/`vmm_space_destroy` route through unref). `vmm_fork_space` shares every present user page COW (`VMM_FLAG_COW`, bit 9): writable pages → RO+COW in both parent and child, code stays RO; `vmm_cow_fault` copies a COW page on the first write (else falls through to the M15 kill path). `SYS_FORK` (18) / `process_fork` copies the PCB + own image (FILE-VMA `file_base` rebased) + manifest + fresh kstack/trapframe (child `rax=0`), drops driver privilege. libc `fork()`. **Key fix**: intermediate page-table entries are now always `RW|PRESENT` (USER still propagated) — x86-64 ANDs RW across all levels, so the leaf PTE is the sole protection authority (was breaking COW). Demo `M19_FORK_DEMO` (`user/m19_fork`): child inherits memory, COW-copies on write, parent's buffer stays isolated, exit status 7 via blocking wait. See `docs/devlog/M19.md`.
- **M20** (unified page cache, closes Phase G) done. A page cache (`mm/pagecache.c`: 128 pages keyed by inode+offset, VFS-populated, FIFO eviction) backs **both** file `read()` and **file-backed `mmap`**, so they're coherent. `SYS_MMAP` gained a `fd` arg: non-anonymous maps the fd's inode (MAP_PRIVATE — `vma_add_file`/`file_inode`; the fault copies the cached page into a private frame, so cache frames stay kernel-only). `ksys_read` routes through `pagecache_read`; `ksys_write` invalidates. libc `open`/`read`/`close`/`mmap_file`. Demo `M20_MMAP_DEMO` (`user/m20_mmap`): mmap a VFS file RO + read() it → identical bytes (coherent). See `docs/devlog/M20.md`.
- **M21** (AHCI/SATA storage) done. New `drivers/ahci.c` — the disk path for **VMware + physical PCs** (which have SATA, not virtio-blk). Probes the AHCI HBA over PCI (`pci_find_class` 01/06/01, ABAR=BAR5 via physmap), IDENTIFYs each established SATA port, and reads/writes via polled DMA (ATA READ/WRITE DMA EXT, single command slot, bounce buffer); registers each disk as `block_dev_t` "sda".."sdd" — FAT32/ext2/ext4 plug in unchanged. Boot mount tries `vda,sda,…,sdd` and mounts the first FAT32/extN volume (the GPT/ESP boot disk is auto-skipped — key for VMware where boot+data are both SATA). Tooling: `make data-vmdk` (FAT32 data disk for VMware), `docs/RUN_ON_HARDWARE.md`. Tested in QEMU q35 (built-in AHCI): ISO+SATA and UEFI+2×SATA both mount RW. See `docs/devlog/M21.md`.
- **M22** (NVMe + USB stack) done. **NVMe** block driver (`drivers/nvme.c`: PCI 01/08/02, 64-bit BAR0 via physmap, admin+I/O queue pairs, IDENTIFY ctrl/ns, polled DMA READ/WRITE with PRP1+PRP-list) registers block dev `nvme0n1` — storage for NVMe-only laptops / VMware NVMe. **USB stack**: a polled **xHCI** controller (`drivers/xhci.c`: PCI 0C/03/30, command/event rings, DCBAA, slot enable → address device → configure endpoint, control/bulk/interrupt transfers, event-ring completion, 32/64-byte contexts via `HCCPARAMS1.CSZ`), a **USB core** (`drivers/usb.c`: descriptor enumeration, SET_CONFIGURATION, class bind), a **HID boot keyboard** (`drivers/usb_hid.c`: boot protocol, non-blocking interrupt-IN poll, key-down edge detect, HID→ASCII, `keyboard_inject_char` into the shared keyboard buffer — polled from `keyboard_has_char`, never an ISR), and **Bulk-Only Mass Storage** (`drivers/usb_msc.c`: CBW/CSW + SCSI INQUIRY/TUR/READ CAPACITY/READ(10)/WRITE(10)) registering block dev `usb0`. `pci_bar_mem64` added. Boot mount tries `vda,sda..sdd,nvme0n1,usb0`. All polled, one op at a time. Tested in QEMU: NVMe (`-device nvme`) FAT32 RW; xHCI+`usb-kbd`+`usb-storage` (keystrokes reach the shell, `usb0` FAT32 RW). **Gotcha**: SeaBIOS hangs trying to boot an NVMe/USB *data* disk → ISO smoke uses `-boot d`. See `docs/devlog/M22.md`.
- **M22 follow-ups** (merged, **DA TESTARE su hardware**): **USB hub** support (`drivers/usb_hub.c` + xHCI route-string/parent-hub addressing) — enumerate devices behind a hub; dormant in QEMU (no hub), emits `[HUB]`. **MSI/MSI-X** plumbing (`drivers/pci.c` cap walk, `arch/x86/lapic.c`, IDT vectors 0x40/0x41, `xhci_enable_irq`/`nvme_enable_irq`) — additive, **OFF by default** (kernel stays polled), gated behind `-DXHCI_USE_IRQ`/`-DNVME_USE_IRQ`, needs LAPIC + hardware validation.
- **M23** (POSIX filesystem personality) done. Goal: compile open-source Linux software *from source* (and sign it) for SecOS. **Trust = signature**: only signed code runs, so a signed program gets ambient `/dev` access like a Linux process (Driver Space orthogonal — a `/dev/<blk>` read still goes through the kernel block driver). **Persistent ext2 root**: `ext2_mount_root` adopts an ext2 volume as `/` only if it carries the marker `/.secosroot` (so data disks aren't grabbed; CI keeps RAMFS root); `make sysdisk-ext2` builds the system-root image (FHS skeleton + marker). **devfs** (`fs/devfs.c`, `/dev`): char (`null/zero/full/random/urandom/console/tty`) + byte-addressed block nodes (`vda/sda/nvme0n1/usb0`). **procfs** (`fs/procfs.c`, `/proc`): generated `meminfo/uptime/version/cpuinfo/mounts/self`. **sysfs** (`fs/sysfs.c`, `/sys`): `/sys/block/<dev>/{size,sector_size}`. `vfs_fs_ops_t.flags` + `VFS_FS_NOCACHE` (virtual FSes bypass the page cache); `VFS_MAX_MOUNTS`→12. New syscalls `SYS_LSEEK` (19) + `SYS_STAT` (20) + libc `lseek`/`stat`. Verified: signed ring-3 `user/m23_fs` opens `/dev/zero`,`/dev/null`,`/proc/uptime` + `stat`/`lseek` a block node (gate `M23_FS_DEMO`); two-boot persistence (`vcreate` then reboot `vcat` = persists). **Foundation, not full Linux compat** — `ioctl`, fuller libc/syscalls, per-pid `/proc` are follow-ups. See `docs/devlog/M23.md`.
- **M24** (networking) done — validated on real VMware. NIC contract (`net/net.h`) + **4 drivers** (e1000 binds 82540EM/82545EM, e1000e binds 82574L — the validated one; vmxnet3 + igc/2.5GbE compile-clean, untested), L2/L3/L4 stack (`net/eth,arp,ipv4,icmp,udp,dhcp,dns,tcp.c`: full TCP state machine + sliding window + retransmit), **BSD sockets + CAP_NET** (`net/socket.c`, syscalls 21–30; `CAP_NET` = bit 4 of the signed manifest `flags`). **RX is interrupt-driven (MSI-X/NAPI) by default** (`net_request_irq`, falls back to polling; opt out `-DNET_NO_MSIX`). Shell `netinfo`/`dhcp`/`ping`/`nslookup`/`udpsend`/`tcptest`/`nettest`. Gate `M24_NET_DEMO`. **RX needs the shell/idle context** (idle `hlt`s → yields the vCPU so QEMU delivers RX DMA — test networking from the shell, not early boot). See `docs/devlog/M24.md`.
- **M25** (pipes + TTY + TCP throughput) done. **Anonymous pipes** (`kernel/pipe.{c,h}`: 4 KB ring + reader/writer refcounts): `SYS_PIPE` (31) → read/write fds (fd table gains `is_pipe`/`pipe_w`); blocking read/write handled in `syscall_trap.c` (rip-rewind + `wait_pipe` + `sched_wake_pipe`, like M16/M17); EOF when `writers==0`, EPIPE when `readers==0`; fork bumps refcounts, close/destroy drop them. **fds 0/1/2 are now reserved as stdin/stdout/stderr at process creation** (else a pipe end collided with the console fd special-cases). **Console TTY** (`kernel/tty.c`): cooked line discipline (echo, backspace, Ctrl-D EOF, Ctrl-C line-cancel) on fd 0 + `/dev/tty`/`/dev/console`; blocks on `sti; hlt` like the socket layer. **TCP throughput**: `TCP_RXBUF`/`TCP_TXBUF` 8K→**64K** (max window without scaling) + deeper NIC RX rings (e1000 64→256, e1000e 32→256). libc `pipe()`. Demo `M25_PIPE_DEMO` (`user/m25_pipe.c`: pipe across fork, blocking read, EOF). **Deferred**: async Ctrl-C→SIGINT + SIGPIPE (need a signal subsystem); shell pipelines. See `docs/devlog/M25.md`.
- **M26** (VFS maturity — Phase H part 1) done. **POSIX metadata stored & exposed, not enforced** (user decision: the Ed25519 signature is the trust boundary, so a signed process has ambient access — no uid-based access checks). `vfs_inode_t` gains `mode/uid/gid/atime/mtime/ctime/nlink` + `VFS_NODE_SYMLINK`; `struct secos_stat` extended (st_size@0/st_mode@8 stable, owner/timestamps appended; st_mode now full POSIX mode). ext2 `e2_lookup` populates metadata from the on-disk inode; `e2_setattr` patches it in place (e2fsck-clean). **chmod/chown/utimes** (`SYS_CHMOD/CHOWN/UTIMES` 32–34) + **lstat** (37, no follow). **Symlinks**: ext2 fast-symlink read/create (`e2_readlink`/`e2_symlink`, ≤60-byte inline target), `vfs_lookup_follow` follows a final-component symlink (8-hop bounded; `stat` follows, `lstat` doesn't), `SYS_READLINK/SYMLINK` (35/36). **mount/umount** (`SYS_MOUNT/UMOUNT` 38/39) over `fat32_mount`/`ext2_mount`/`vfs_unmount`. libc gains all wrappers + extended `struct stat`. Demo `M26_FS_DEMO` on ext2 `/mnt`; verified host-side (`e2fsck` clean, `debugfs` shows mode 0640 / uid 1000 / fast symlink). **Limitation**: mid-path symlink components not followed yet. See `docs/devlog/M26.md`.
- **M27a** (JBD2 journal replay — Phase H part 2, read-side) done. Makes SecOS safe to mount an ext3/ext4 volume left **dirty** by a crash on another OS: `jbd2_recover()` (`fs/ext2.c`, runs in `ext2_mount`/`ext2_mount_root`) replays committed-but-not-checkpointed transactions before mounting. No-op unless `HAS_JOURNAL` + journal non-empty (`s_start!=0`). JBD2 is **big-endian** (dedicated `be32/be16`). Standard **3-pass** recovery (SCAN counts committed txns → REVOKE builds the revoke table → REPLAY writes journalled blocks honouring revokes); handles v2/v3 tags, 64-bit block numbers, ESCAPE, per-tag UUID; csums not verified (replay regardless → compatible with csum journals). After replay, marks the journal clean (`s_start=0`) + clears fs `NEEDS_RECOVERY` so it doesn't recover twice and stays e2fsck-clean. **Verified root-free, e2fsck-validated**: `tools/mk_dirty_journal.py` synthesizes a dirty journal (target block OLD→NEW), `e2fsck -fy` on a copy replays it (ground truth), SecOS replays identically (`[M27] REPLAY OK`), post-replay `e2fsck -fn` clean. `make disk-journal`, gate `M27_RECOVER_DEMO`. **Deferred (M27b)**: write-side journaling (SecOS's own writes crash-safe) + `metadata_csum` + fault-injection harness. See `docs/devlog/M27.md`.
- **M27b** (write-side journaling — **Phase H complete**) done. SecOS's own ext3/ext4 metadata writes are now **crash-atomic**. `fs/ext2.c`: each mutating VFS op runs as one **metadata transaction** (`e2j_*` wrappers) — `blk_write` buffers metadata into the txn (dedup), file **data** + new-block zeroing use `blk_write_direct` (ordered mode: data before commit), and `blk_read` is **read-your-writes** (serves buffered blocks so RMW of shared metadata — group desc/superblock/bitmaps — accumulates instead of clobbering; this was the one bring-up bug). `jt_commit` writes the JBD2 txn (descriptor+blocks+commit), **publishes** `s_start`, **checkpoints** in place, **retires** `s_start=0`; failure → `jt_abort` (atomic rollback); no-journal volume → legacy direct writes; only csum-free/non-async journals are written (`jt_init`). **Crash-atomicity proven** with a fault-injection harness (`g_blk_dead` drops writes at two precise commit points): crash *before commit* → op absent (old state), crash *after publish* → recovery (M27a) replays → op present (new state), **always e2fsck-clean, never torn**. Gates `M27B_CRASH=1|2` (run1 crash) + `M27B_VERIFY` (run2 recover/report). `metadata_csum` intentionally not implemented (journals to `^metadata_csum` volumes; orthogonal follow-up). ## Build & run

```bash
make            # build kernel.bin (default target)
make uefi       # build UEFI bootloader -> dist/EFI/BOOT/BOOTX64.EFI (also copies kernel.bin to dist/kernel.elf)
make iso        # build myos.iso (GRUB Multiboot2 bootable)
make run        # build iso + run in QEMU with -debugcon stdio (all run* targets boot the persistent root secos-root.img; ROOT=ram = no disk)
make reset-root # DELETE secos-root.img and create a fresh system disk
make clean      # remove objects, kernel.bin, iso, dist/
make iso SSH_AUTHORIZED_KEYS=~/.ssh/id.pub   # bake SSH public key(s) -> /root/.ssh/authorized_keys (never commit keys)
```

There is no separate lint step. `CONTRIBUTING.md` asks contributors to build clean under `-Wall -Wextra` locally.

Toolchain (Debian/Ubuntu): `nasm gcc binutils gnu-efi ovmf qemu-system-x86 mtools grub-common grub-pc-bin xorriso`.

## Testing (smoke tests)

There is no unit-test framework. Correctness is validated by **deterministic QEMU smoke tests** plus an **in-kernel selftest suite**.

```bash
tools/smoke.sh --mb2  --timeout 20 --log /tmp/secos_mb2.log    # Multiboot2/GRUB path
tools/smoke.sh --uefi --timeout 25 --log /tmp/secos_uefi.log   # UEFI/OVMF/q35 path
```

PASS/FAIL criterion (counterintuitive): a triple fault resets the CPU and, with `-no-reboot`, QEMU exits **before** the timeout (exit 1 = FAIL). A healthy kernel keeps running until `timeout(1)` kills it (exit 124, which the script remaps to **exit 0 = PASS**). So "the process getting killed by timeout" is the success signal.

The kernel writes crash-signature markers to ISA debugcon port `0xE9`, forwarded by QEMU to the `--log` file. Expect lines like `SECoS build <BUILD_TS> git:<GIT_HASH>` and `[M2] Stack switch ok. RSP=...`.

The isolation selftest (12 cases for `user_range_valid`/`copy_from_user`/`copy_to_user`) runs at boot when `M4_SELFTEST_ENABLE=1` (the default) and logs `[M4][SELFTEST]` lines via debugcon. Disable with `make iso CFLAGS_EXTRA=-DM4_SELFTEST_ENABLE=0`. To exercise other subsystems, use the interactive shell commands (`memtest`, `memstress`, `elfload`/`elfunload`, `drvtest`, RAMFS `rf*` and VFS `v*` commands) — these are the de-facto test harness.

## Boot architecture (the part that needs multiple files to understand)

One binary supports both boot paths; `kernel_main(magic, info)` disambiguates at runtime:
- `magic == 0` → **UEFI**; `info` is a `struct secos_boot_info*` (see `kernel/bootinfo.h`), populated by the external bootloader in `uefi/boot.c` (`efi_main`) which ELF-loads the kernel and calls `_uefi_start` (64-bit) in `boot/boot.asm`.
- `magic == 0x36d76289` → **Multiboot2**; `info` is the MB2 info pointer. `_start` (32-bit) in `boot/boot.asm` sets up long mode, then jumps to `long_mode` (64-bit) → `kernel_main`.

`kernel_main` saves the boot magic/info into globals (`g_multiboot_magic`, `g_multiboot_info`), does early init, then **switches to the hardened virtual kernel stack** and tail-calls `kernel_main_phase2()` via `trampoline_switch_stack`. Phase 2 re-reads the globals to finish framebuffer/PMM/etc. init. This two-phase split exists because the stack pointer changes mid-init, so don't assume locals survive across the trampoline — pass state through globals or the boot-info struct.

Build defines `BUILD_TS` and `GIT_HASH` (from the Makefile) are compiled in and surfaced in the debugcon banner and the RAMFS `VERSION` file; they are how a running image is traced back to a build.

## Code layout

- `boot/` — MB2 (`_start`, 32-bit) and UEFI (`_uefi_start`, 64-bit) entry, in `boot.asm`.
- `arch/x86/` — IDT, TSS, syscall entry (`syscall_asm.asm`), context switch (`context_switch.c` + `context_switch_asm.asm`). Trapframe-based.
- `kernel/` — `kernel.c` (init), `process.c` + `sched.c` (PCB/scheduler), `syscall.c` + `syscall_trap.c` (dispatch), `driver_if.c` (Driver Space mediation), `shell.c`, `selftest.c`, `panic.c`.
- `mm/` — `pmm.c` (frame allocator), `vmm.c` (paging, kernel-owned page tables, W^X/NX), `heap.c` (kmalloc/kfree), `elf*.c` (ELF64 loader, `.note.secos` manifest parsing, precise per-process unload), `user_copy.c` (`user_range_valid`, `copy_from/to_user`).
- `fs/` — `vfs.c` abstraction over `ramfs` (root), `fat32`, `ext2` (+ `ext2ramdev`), `block.c`.
- `drivers/` — framebuffer (`fb`, `fb_console`, `fbdev` = `/dev/fb0`), keyboard (+ `keymap`), PS/2 mouse, input core/evdev (`input`), USB (xHCI/HID/MSC), timer (PIT/IRQ0), RTC.
- `uefi/` — the external UEFI bootloader (`boot.c`, `elf_load.c`, `crt0.s`, `efi.h`), built separately by `make uefi`.
- `config.h` — compile-time feature toggles (`ENABLE_*`) and `CONFIG_MULTIBOOT`/`CONFIG_UEFI` (both can be 1 for dual-boot; at least one is required).

`edk2/` is a large untracked vendored tree (alternative `edk2_bootloader/` path); it is not part of the default build.

## Security & style invariants (enforced by review, not tooling)

- **W^X**: never map a page writable and executable at once; W|X ELF segments are rejected unconditionally by the loader.
- **NX** on all data/stack regions; **never set the USER bit on kernel pages** (`vmm_map`/`vmm_map_in_space` enforce supervisor; PML4[256+] is asserted kernel-only).
- All syscall user pointers must go through `user_range_valid` + `copy_from/to_user` — never dereference a user pointer directly in the kernel (this is the M3 hardening contract).
- ELF segments must have `p_align` of 0 or 0x1000; track allocated pages per process for precise unload/accounting; user stacks get a guard page.
- C99 freestanding, 4-space indent (no tabs), K&R braces, explicit fixed-width types (`uint64_t`), domain-prefixed static helpers (`vmm_`, `pmm_`, `drv_`).
- Code, comments, and docs in **English only** — no mixed Italian/English (existing files still contain some Italian; don't add more).
- Topic branches (`feat/...`, `fix/...`, `docs/...`), imperative commit subjects, one logical change per commit.
