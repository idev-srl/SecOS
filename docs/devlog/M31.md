# M31 — Real C library + coreutils userland (Phase K)

Phase K turns SecOS from "runs a few bespoke signed programs" into "has a real
userland you can build software for". M31 is the libc + a coreutils suite; M32 is
the signed package format + a service manager.

## M31a — the C library

`user/include/` now holds standard headers (`string.h`, `stdio.h`, `stdlib.h`,
`ctype.h`, `unistd.h`, `errno.h`, `assert.h`, `time.h`, `fcntl.h`, `dirent.h`,
`sys/stat.h`, `sys/types.h`) so open-source C can be compiled from source with the
usual `#include <...>`. `user/libc.c` implements them over the custom syscall ABI
(`libsecos.c` keeps the raw wrappers):

- **ctype**: full `is*`/`to*`.
- **string**: `mem*`, `str*` (cmp/ncmp/casecmp/cpy/ncpy/lcpy/cat/chr/rchr/str/
  dup/tok/spn/cspn/pbrk), `strerror`.
- **stdlib**: `malloc/free/calloc/realloc` (moved here from libsecos so `realloc`
  can read the block header), `atoi/atol/strtol/strtoul`, `qsort/bsearch`, `rand/
  srand`, `abs/labs`, `exit/abort`, `getenv` (stub).
- **stdio**: a **sink-based printf core** (`fmt_core`) supporting flags
  (`-0+ #`), width/precision (incl. `*`), length (`l`/`ll`/`z`/`h`) and
  `d i u x X o c s p %` → `printf/fprintf/snprintf/vsnprintf/dprintf/sprintf`,
  plus a buffered `FILE` layer (`fopen/fdopen/fclose/fread/fwrite/fgets/fgetc/
  ungetc/fputs/fputc/putchar/getchar/fflush/feof/ferror/ftell/fseek/perror`,
  `stdin/stdout/stderr`).
- **time/errno/assert**: `time()/clock()` (ticks-based), the `errno` global,
  `__assert_fail`.

Build: `USER_CFLAGS += -Iuser/include`; `libc.o` links into every user program
(plain object, `--gc-sections` strips what a given program doesn't use). **GCC
nested functions / statement-expressions are avoided** — they emit an
executable-stack trampoline, which the kernel's W^X would (correctly) kill.

Verified: signed `user/m31_libc` runs in ring 3 (gate `M31_LIBC_DEMO`; stdout
mirrors to debugcon) — 16/16 PASS (printf width/precision/long/ptr, string,
strtol, malloc/realloc, qsort, ctype), `[m31] DONE fails=0`, no `[EXC]`.

## M31b — file-management syscalls + coreutils

A real userland needs to enumerate and mutate the FS. New syscalls over the
existing VFS:
- **SYS_GETDENTS (40)** — packed 256-byte dir records `{char d_type; char
  d_name[255]}` (via `vfs_readdir`); the libc `<dirent.h>`
  (`opendir/readdir/closedir`) sits on top.
- **SYS_CREATE (41)** / **SYS_MKDIR (42)** / **SYS_UNLINK (43)** — over
  `vfs_create`/`vfs_mkdir`/`vfs_remove`. libc: `creat_file/mkdir/unlink/rmdir`.

**coreutils** is a busybox-style multi-call binary: `user/coreutils.c` dispatches
to an applet by `basename(argv[0])` (or `argv[1]` when invoked as the bare
`coreutils`). 26 applets across `cu_text.c` (echo, cat, wc, head, tail, rev, nl,
yes, seq), `cu_file.c` (ls, mkdir, rm, touch, cp, basename, dirname, stat) and
`cu_misc.c` (true, false, uname, sleep, clear, hexdump, uptime, help). One signed
ELF, installed to `/bin` under every applet name at boot (idempotent on a
persistent root) so `run /bin/ls /`, `run /bin/cat <f>`, `run /bin/wc <f>`, etc.
work. `RAMFS_MAX_FILES` 32→96 to hold the `/bin` entries.

Verified in QEMU: echo/seq/cat/wc/uname/mkdir/touch/**ls (getdents)**/**rm
(unlink)**/**hexdump**/stat all produce correct output; gate `M31_LIBC_DEMO` also
runs echo/wc/uname. Selftest gains 7 M31 cases.

**Limitations / follow-ups:** `open(O_CREAT)` still doesn't create (use
`creat_file`); no `getcwd`/cwd for userland (so `pwd` is a shell builtin); `qsort`
uses a bounded scratch buffer (element size ≤ 256). Floats in `printf` (`%f/%g`)
not implemented yet.
