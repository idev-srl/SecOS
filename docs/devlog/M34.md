# M34 — Phase K self-hosting: libc float/setjmp/math + lua 5.4.7 from source

**Headline:** a real open-source program (lua 5.4.7) compiled **from source**,
signed, and run in ring-3 on SecOS — the proof of the "compile OSS from source"
thesis.

## libc gaps filled (`user/`)

- **printf `%f/%e/%g/%a`** — hardware double via SSE; `dtoa_round` extracts
  significant digits with a *single exact power-of-ten scale* (≈0.5 ULP, no
  per-digit accumulation). Verified against glibc: bit-exact on the lua-relevant
  `%.14g` cases (only ties like `2.5 %.0f` differ, round-half-away vs even).
- **`strtod`/`strtof`/`atof`**, `strtoll`/`strtoull`, `strcoll`/`strxfrm`,
  `freopen`.
- **`setjmp`/`longjmp`** (`user/setjmp.S`, x86-64) — lua's `LUAI_THROW`.
- **`math.h` + `user/libm.c`** — `floor/ceil/trunc/round/sqrt`(hw)`/fmod/pow/exp/
  log/log2/log10/sin/cos/tan/asin/acos/atan/atan2/sinh/cosh/tanh/ldexp/frexp/
  modf/...` (range-reduced series; good enough for ports, not bit-exact).
- `locale.h` stub, `sig_atomic_t`.

## Kernel: SSE for ring-3

`cpu_enable_sse()` sets `CR0.MP`/`!EM`, `CR4.OSFXSR`/`OSXMMEXCPT`, `fninit`,
default MXCSR — on the **BSP** (`kernel_main`) and each **AP** (`ap_entry`) — so
ring-3 FP runs without `#UD`. The kernel stays `-mno-sse` (never clobbers XMM).
The `[SYSCALL]` and `[PF] demand page` debug traces are now gated on `g_kverbose`
so they don't interleave with a program's output.

## lua port

`third_party/lua/src` (vendored) + `user/lua_main.c` (freestanding front-end) +
`user/lua_port.h` (force-included config: output via `write()`, radix `'.'`).
Compiles the lua **core + OS-independent libs** (base/table/string/math/
coroutine/utf8) against the SecOS libc; skips io/os/loadlib/lua.c. `make
port-lua` builds + signs it → `crypto/user_lua_elf.h`. Gate `M34_LUA_DEMO=1`.

All values correct. Both smoke paths PASS.

## Toward bash

The hard kernel primitives bash needs (fork/exec/pipes/signals/job control) are
already in. The remaining libc/syscall surface for bash: **termios + ioctl**
(tcgetattr/tcsetattr/tcsetpgrp/TIOCGWINSZ), `dup2`/`fcntl`, `waitpid`
WUNTRACED/WIFSTOPPED, and a cross-compile `config.h` harness. `dash`/busybox-ash
is a closer stepping stone than bash 5.x.
