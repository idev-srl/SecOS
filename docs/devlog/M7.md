## Summary

M7 wires the M6 trapframe machinery into an actual ring-0 → ring-3 transition
and a cooperative scheduler driven by a `SYS_YIELD` syscall. The intent is to
run two ring-3 processes that repeatedly `INT 0x80` (yield) and hand control
back and forth.

Relevant commit:
- `73a45db` M7 done

---

## Changes

- `kernel/syscall.h` — defines `SYS_YIELD` as syscall number `0`.
- `kernel/syscall_trap.c` — `syscall_handler` intercepts `SYS_YIELD` and calls
  `sched_yield_from_syscall(tf)`, which does not return when it switches.
- `kernel/sched.c` / `kernel/sched.h` — `sched_set_current()` and
  `sched_yield_from_syscall(trapframe_t*)`: saves the caller trapframe into the
  persistent `current->tf` (yield returns 0), picks the next `READY` process,
  sets `vmm_switch_space` + `tss_set_kernel_stack`, logs `[SCHED] switch <a> -> <b>`,
  and `arch_iret_to_tf(next->tf)`.
- `arch/x86/context_switch.c` — `arch_enter_user_mode(process_t*)` performs the
  first entry into ring-3.
- `kernel/kernel.c` (`kernel_main_phase2`) — builds a synthetic 512-byte ELF in
  a stack buffer whose code is `mov rax,0 / int 0x80 / jmp loop`, creates two
  processes from it, marks p1 RUNNING / p2 READY, then calls
  `arch_enter_user_mode(p1)` (marked `// NOT REACHED`).

## Current runtime state (HEAD, build `73a45db`)

Reproduced with `tools/smoke.sh --mb2`:

- Build clean; kernel boots; 12/12 isolation selftests PASS; no triple fault
  (smoke test exits 124 → PASS, i.e. the kernel stays alive).
- Debugcon output stops at:

  ```
  [M7] Creating two ring3 yield-loop processes
  ```

  The expected follow-up lines (`[M7] p1 pid=...`, `[M7] Entering ring3`,
  `[SCHED] switch ...`) **never appear**. This places the stall inside the two
  `process_create_from_elf()` calls, before ring-3 is entered. No context
  switch is observed.

- Because the demo block in `kernel_main_phase2` ends with `arch_enter_user_mode`
  (marked `// NOT REACHED`), it short-circuits the rest of boot: RAMFS/VFS init
  and the interactive shell are not reached even if the demo worked.
