# M37 — Boot integrity: measured boot + reproducible builds (Phase L pt 3)

- **Measured boot.** `boot_measure()` computes a SHA-256 over the immutable
  kernel image (`.text` + `.rodata`, via the linker `_text_start`/`_rodata_end`
  symbols) and records it on debugcon:
  `[M37] kernel code measurement (sha256 .text+.rodata): <hash>`. This is the
  measurement primitive of an attestable boot chain (a TPM would extend a PCR
  with it). Combined with the already-verified signed userland (M9), the chain is
  **loader → kernel measurement → signed programs**.
- **Reproducible builds.** `BUILD_TS` now derives from `SOURCE_DATE_EPOCH` when
  set (the reproducible-builds.org standard), so the same source tree produces a
  **byte-identical `kernel.bin`** — verified: two builds hash identically — and
  therefore a stable measured-boot hash that can be attested.

  ```
  make iso SOURCE_DATE_EPOCH=$(git log -1 --format=%ct)
  ```

Both smoke paths PASS, 0 warnings/exceptions.
