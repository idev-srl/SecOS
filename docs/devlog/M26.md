# M26 — VFS maturity (Phase H, part 1)

_Status: code complete, build clean, demo verified non-interactively
(`M26_FS_DEMO`) and host-side (`e2fsck -fn` clean, `debugfs` confirms metadata +
symlink persisted). First half of Phase H (storage & filesystem maturity); M27
(crash consistency / ext4 journaling) is the second half._

## Scope & design decision

Phase H's first milestone: POSIX metadata, symlinks, robust path resolution, and
`mount`/`umount` syscalls. (devfs `/dev` + procfs `/proc` already shipped in M23.)

**Key decision (user, 2026-06-19):** permissions are **stored & exposed, not
enforced**. The roadmap's exit criterion said "multi-user permissions enforced",
but that contradicts SecOS's locked model where **the signature is the trust
boundary** (a signed process has ambient access). So we persist and report
`mode`/`uid`/`gid`/timestamps (POSIX-correct on disk, `e2fsck`-clean,
Linux-readable) and `chmod`/`chown`/`stat` work — but there is **no uid-based
access check**. This keeps OSS source-ports happy without introducing a parallel
multi-user identity model. See `memory/m25-tcp-throughput-findings.md` siblings.

## What landed

### Inode metadata + extended stat
- `vfs_inode_t` gains `mode`, `uid`, `gid`, `atime`, `mtime`, `ctime`, `nlink`
  and a new node type `VFS_NODE_SYMLINK`.
- `struct secos_stat` (ABI) extended: `st_size`@0 and `st_mode`@8 kept stable;
  appended `st_nlink`/`st_uid`/`st_gid`/`st_atime`/`st_mtime`/`st_ctime`.
  `st_mode` is now the full POSIX mode (S_IFMT type bits | perms). All user
  programs were rebuilt/re-signed (`make user-progs`) for the new ABI.
- `ext2` `e2_lookup` populates the metadata from the on-disk inode (standard
  layout: i_mode@0, i_uid@2, i_atime@8, i_ctime@12, i_mtime@16, i_gid@24,
  i_links@26) and flips `type` to symlink for `S_IFLNK`. `ksys_stat`/`ksys_lstat`
  synthesize sane defaults when an FS leaves `mode==0` (ramfs/devfs/procfs/sysfs).

### chmod / chown / utimes (setattr)
- New `vfs_fs_ops.setattr(path, vfs_attr_t*, valid)` with a `VFS_ATTR_*` bitmask.
  `ext2` patches the on-disk inode in place (chmod preserves the S_IFMT type bits,
  setting only the low 12 perm bits) and stays `e2fsck`-clean.
- Syscalls `SYS_CHMOD` (32) / `SYS_CHOWN` (33) / `SYS_UTIMES` (34) + libc
  `chmod`/`chown`/`utimes`. ctime is not auto-bumped (no wall-clock dependency;
  not needed for fsck-cleanliness) — a minor follow-up.

### Symlinks + path resolution
- `ext2` `e2_readlink` (fast symlinks inline in i_block ≤60 bytes, plus the slow
  block-0 form) and `e2_symlink` (creates a fast symlink: `S_IFLNK|0777`, target
  inline, `DT_LNK` dir entry). Larger-than-60-byte targets are rejected for now.
- `vfs_lookup_follow()` follows a **final-component** symlink (bounded to 8 hops
  to catch loops; absolute targets replace the path, relative targets join the
  link's directory). `stat()` follows; `lstat()` (new, `SYS_LSTAT` 37) does not.
- Syscalls `SYS_READLINK` (35) / `SYS_SYMLINK` (36) + libc `readlink`/`symlink`.
- **Limitation:** mid-path symlink components (`/a/b/c` where `/a/b` is a link)
  are not followed yet — the FS walks intermediate components as directories.

### mount / umount
- `SYS_MOUNT` (38) `(dev, target, fstype)` and `SYS_UMOUNT` (39) `(target)` over
  the existing `fat32_mount`/`ext2_mount`/`vfs_unmount` (the same path the boot
  mount and shell `mountdev` use). fstype: `fat32`/`vfat`, `ext2`/`ext4`/`extN`,
  or `auto`/`""` (try both). libc `mount`/`umount`. Signature is the trust
  boundary, so any signed caller may mount.

## Verification

Demo gate `M26_FS_DEMO` on an ext2 `/mnt` (the substantive VFS layer; the
syscalls are thin wrappers and the `stat` syscall path is also covered by M23):
```
[M26] chmod 0640 -> mode=0x...1A0          (0640)
[M26] chown 1000:1000 -> uid=0x...3E8 gid=0x...3E8
[M26] symlink rc=0 readlink=7 target="m26.txt"
[M26] lstat type=3 stat-follow type=1      (symlink vs followed file)
[M26] umount rc=0 remount rc=0
[M26] DONE
```
**Host-side**: after the run, `e2fsck -fn disk.img` is **clean** and
`debugfs -R "stat /m26.txt"` shows `Mode: 0640  User: 1000  Group: 1000`, and
`/m26.lnk` is `Type: symlink  Fast link dest: "m26.txt"` — fully POSIX/Linux
interoperable. selftest adds 7 M26 cases.

## Files touched

- `fs/vfs.h` (inode metadata, `vfs_attr_t`, new ops, `vfs_lookup_follow`),
  `fs/vfs.c` (setattr/readlink/symlink routing + `vfs_lookup_follow`).
- `fs/ext2.c` (metadata in lookup, `e2_setattr`, `e2_readlink`, `e2_symlink`).
- `kernel/syscall.{c,h}` (lstat/chmod/chown/utimes/readlink/symlink/mount/umount,
  `copy_user_str`, stat follows symlinks).
- `user/libsecos.{c,h}` (wrappers + extended `struct stat`).
- `kernel/kernel.c` (`M26_FS_DEMO` gate), `tools/selftest.sh` (M26 cases).

## Open follow-ups
- Mid-path symlink following; `../` normalization in relative target join.
- ctime auto-bump (needs a wall-clock; RTC→epoch helper).
- Slow symlink **creation** (>60-byte targets).
- Device-node mode in stat (devfs returns S_IFREG via the synthesis fallback).
- **M27 — crash consistency**: ext4 JBD2 journaling + `metadata_csum`, writeback
  ordering, power-fail safety (fault-injection tested). Completes Phase H.
