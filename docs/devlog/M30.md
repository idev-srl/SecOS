# M30 — Signals + job control + shell pipelines

_Phase F follow-up (the deferred "async Ctrl-C→SIGINT + SIGPIPE" from M15/M25),
taken all the way to **full job control**._

## Goal

Give ring-3 processes real POSIX-style signals — asynchronous delivery, custom
handlers, default actions — and build on them: a foreground process group that
Ctrl-C/Ctrl-Z reach, SIGPIPE/SIGCHLD, EINTR on interrupted syscalls, **shell
pipelines** (`a | b | c`) and **job control** (`&`, `jobs`, `fg`, `bg`,
Ctrl-Z/SIGCONT).

## What shipped

### Signal core (`kernel/signal.{c,h}`)
- `process_t` gains `sig_pending` / `sig_blocked` (64-bit masks, bit n = signal
  n), `sig_handler[32]` (disposition: `SIG_DFL`/`SIG_IGN` or a user handler VA),
  `sig_restorer` (the libc trampoline), `pgid`/`ppid`, and a new `PROC_STOPPED`
  state.
- **Delivery chokepoint** `signal_dispatch(tf)` is called from the three
  return-to-ring-3 asm stubs — `syscall_entry` (after the rax patch),
  `isr_timer` (non-preemptive return), and `isr_common` (a handled ring-3
  exception). It only acts when returning to ring-3 (`(cs&3)==3`). For each
  deliverable pending signal it does the **default action** (terminate via
  `sched_kill_current`, stop via the new `sched_stop_current`, or ignore for
  SIGCHLD/SIGCONT) or sets up a **custom handler frame** on the user stack.
  The terminate/stop paths never return (they switch to another task), exactly
  like a timer preemption — abandoning the asm stub mid-restore is fine.
- **Custom handler**: a `sigframe_t` (magic + saved mask + the full interrupted
  `trapframe_t`) is pushed below the user `rsp` (past the 128-byte red zone,
  16-aligned), with the `sig_restorer` address as the handler's return address.
  `tf` is rewritten: `rip=handler`, `rdi=signum`, `rsp` at the frame
  (`rsp%16==8` at entry, per the ABI). The signal is masked while its handler
  runs.
- **SYS_SIGRETURN** reads the sigframe back from the user `rsp`, restores
  `sig_blocked` and the saved `tf` **in place** (forcing ring-3 selectors + IF
  and rejecting a non-user `rsp`, so a forged frame can't escalate), and returns
  the interrupted code's original `rax`.
- **Syscalls**: `SIGACTION(44)` / `SIGRETURN(45)` / `KILL(46)` /
  `SIGPROCMASK(47)` / `SETPGID(48)`. SIGKILL/SIGSTOP are uncatchable and
  unblockable. `kill(pid<=0, …)` addresses the caller's process group.

### Async sources
- **Ctrl-C / Ctrl-Z** (`drivers/keyboard.c`): when a **foreground process
  group** owns the console (`signal_set_foreground_pgid`), the control keys are
  posted as `SIGINT` / `SIGTSTP` to that group instead of being buffered. At the
  shell prompt (no foreground group) they fall through to the line-editing codes
  as before. Posted after releasing `kbd_lock` (avoids nesting it under
  `proc_lock`).
- **SIGPIPE** (`kernel/pipe.c`): writing to a reader-closed pipe posts SIGPIPE
  (in addition to the EPIPE return).
- **SIGCHLD** (`kernel/sched.c`): a child's exit/kill/stop notifies its parent
  (`ppid`).
- **EINTR**: the blocking syscalls (`SYS_WAIT`/`SLEEP`/`MSG_RECV`/pipe `read`/
  `write`) and the TTY read spin return `-EINTR` (`-4`) when a signal is
  pending; `signal_post` wakes a `PROC_BLOCKED` target (clearing its wait
  condition) so the syscall re-runs, sees the pending signal and returns.

### Userland (`user/`)
- `libsecos.c`: `signal()`, `kill()`, `raise()`, `sigprocmask()`, `setpgid()`.
- `__sigreturn` trampoline in `crt0.S` — lives in the **RX code segment** (no
  executable stack, W^X-clean); libc passes its address as the `sa_restorer`.
- `<signal.h>` (`user/include/signal.h`): the SIG* numbers + SIG_DFL/IGN/ERR.

### Shell — pipelines + job control (`kernel/shell.c`)
- A pipeline `cmd1 a | cmd2 | …` is parsed into stages; the kernel creates each
  program with `process_create_from_elf_args`, wires the inter-stage **pipes**
  (`pipe_alloc`) onto the children's `fds[0]`/`fds[1]` before they run, and puts
  the whole pipeline in **one process group** (the first child's pid). To make
  the redirection work, `ksys_read`/`ksys_write` now give a redirected pipe/file
  end on fd 0/1/2 **precedence** over the console special-case.
- A **foreground** pipeline sets `foreground_pgid` and the shell (running as the
  idle task) waits until the group finishes or stops (`job_wait_foreground`).
- **Background** (`&`): the pipeline is launched without waiting and recorded as
  a job; `[n] pgid` is printed.
- **Ctrl-Z** stops the foreground group (SIGTSTP → `PROC_STOPPED`); the shell
  records it as a Stopped job and returns to the prompt.
- Builtins **`jobs`** (list), **`fg [%n]`** (SIGCONT + foreground wait),
  **`bg [%n]`** (SIGCONT, background). `kill` is now signal-based
  (`kill [-SIG] <pid>|%job`, default SIGTERM).

## Demo + verification

Gate `M30_SIGNAL_DEMO` (`user/m30_sig.c`): a signed ring-3 program installs a
SIGUSR1 handler, `raise()`s it (delivery + sigreturn proven), then `SIG_IGN`s
SIGPIPE and writes to a reader-closed pipe (EPIPE without termination).

Verified in QEMU (debugcon):
```
[SIG] deliver sig=0x000000000000000A pid=0x...1 handler
[m30] caught SIGUSR1
[m30] sigreturn ok
[m30] sigpipe epipe ok
[M30] DONE
```

Pipelines + background verified over the serial console:
```
secos:/$ seq 1 100 | wc            -> 100 100 292
secos:/$ seq 1 9 | head -3 | wc    -> 3 3 6
secos:/$ seq 1 20 &                -> [1] 1   (prompt returns; seq runs in bg)
secos:/$ jobs                      -> no jobs / lists Stopped+Running jobs
```

Self-test: new M30 section asserts the demo markers; suite stays green.

## Notes / limitations
- **Async Ctrl-C/Ctrl-Z and fg/bg of a stopped job** need the PS/2 keyboard IRQ
  (serial input is polled, so it can't asynchronously interrupt a compute-bound
  process). The mechanism is proven non-interactively (the demo's `raise()` +
  the timer-return chokepoint); the interactive keyboard path mirrors the
  VMware-verified M28-2/M25 keyboard handling — **validate interactively on
  VMware / real HW**.
- `sa_mask`/`sigaction` flags (SA_RESTART, SA_SIGINFO) are not modeled — `signal()`
  is the one-handler-per-signal classic semantics. SA_RESTART-style restart of
  an interrupted syscall is not done (interrupted blocking syscalls return EINTR).
- Sessions / controlling-terminal (`tcsetpgrp`, SIGTTIN/SIGTTOU enforcement) are
  represented only by the single `foreground_pgid` — enough for one console.
- No `waitpid`-reported stop status (`WIFSTOPPED`); the shell tracks stops via
  the `PROC_STOPPED` state directly.
