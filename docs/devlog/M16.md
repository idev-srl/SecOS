# M16 — Exec model: argv/env + blocking wait + exit status

**State:** done. Self-test harness **70/70** (was 66/66; +4 M16 assertions).
Demo gated behind `M16_EXEC_DEMO`, off by default. Phase F (process model).

## Goal

Turn "spawn a program" into a real exec: pass **argv/env** to ring-3 programs,
and let a parent **block** until a child exits and read its **exit status**.
Before M16, spawned programs got zeroed registers (no arguments) and `SYS_WAIT`
was a non-blocking poll returning only running/done — no status.

## What landed

### argv/env on the user stack — `kernel/process.c`
`process_create_from_elf_args(buf, size, argc, argv)` (the old
`process_create_from_elf` is now a 0-arg wrapper) builds the initial user stack:
the argv strings, then a NULL-terminated `argv[]` pointer array and an empty
`envp[]`, all written **top-down** into the demand-paged stack VMA. Two helpers:
- `uwrite(p, va, src, n)` writes into a **not-yet-running** address space, faulting
  in the backing stack pages on demand (`vma_find` + `vma_fault_in`) and writing
  through the physmap (`phys_to_virt(vmm_translate_in_space(...))`).
- `setup_user_args(...)` lays out the stack and returns the 16-byte-aligned `rsp`
  plus the user VAs of `argv[]`/`envp[]`.

The entry is then handed `rdi=argc`, `rsi=argv`, `rdx=envp` (System V convention),
so `int main(int argc, char** argv, char** envp)` works and `int main(void)`
programs simply ignore the extra registers — **`crt0.S` needs no change** (it never
clobbers rdi/rsi/rdx before `call main`). Bounds: `PROC_MAX_ARGS=16`,
`PROC_MAX_ARG_LEN=256`; overflow falls back to argc=0 rather than refusing to run.

### SYS_SPAWN carries argv — `kernel/syscall.c`
`SYS_SPAWN` gains a second argument: `a1 = char**` (NULL-terminated user array,
or NULL). The dispatcher copies the pointer array and each string into the kernel
(all accesses `copy_from_user`-bounce-buffered, capped at `8 × 128`), then calls
`ksys_spawn_argv(path, argc, argv)`. libc: `int spawn(const char* path, char* const argv[])`.

### Blocking SYS_WAIT + exit status — `kernel/syscall_trap.c`, `kernel/sched.c`
- `process_t` gains `exit_code` (set in M15) plus `wait_pid` / `wait_result` /
  `wait_ready`. `SYS_EXIT` now records the user's status into `exit_code` (it was
  hard-coded to 0).
- `SYS_WAIT` is handled in `syscall_handler` (it may block, so it needs the
  trapframe). If the child is gone or already a zombie, it returns the status
  immediately; otherwise it **blocks**: arm `wait_pid`, rewind `rip` by 2 so the
  `int 0x80` re-runs on wake, and `sched_block_current` switches away.
- When a process exits/dies (`sched_exit_current` / `sched_kill_current`),
  `sched_wake_waitpid(pid, code)` finds the blocked waiter, **delivers the status
  into the waiter** (`wait_result`/`wait_ready`) and flips it `PROC_READY`. The
  woken `SYS_WAIT` re-runs, sees `wait_ready`, and returns the status. Delivering
  into the waiter avoids a race with the idle reaper destroying the zombie first.

libc: `int waitpid(int pid)` returns the status (0 = normal exit, `128+vec` =
killed by a fault, per M15).

### The blocking mechanism (shared with M17)
A blocking syscall **rewinds `rip` by 2** (the size of `int 0x80`) before blocking,
so on wake `iretq` re-executes the syscall, which re-checks its condition and
either completes or blocks again. Idempotent, no continuations, and the syscall
args survive in the saved trapframe. `sched_block_current(tf)` saves the
mid-syscall trapframe, marks `PROC_BLOCKED` (skipped by `pick_user`), and switches
to the next runnable task. This same primitive powers M17's sleep and recv.

### Demo + harness — `kernel/kernel.c` (`M16_EXEC_DEMO`), `user/m16_{parent,child}.c`
The kernel drops the signed `m16_child` ELF into the VFS, then spawns the signed
`m16_parent`. The parent `spawn("/m16_child.elf", {alpha,beta})`, blocks in
`waitpid`, and the child prints `argc=3` and exits with status 3; the parent
prints `child status=3`. Four assertions.

## Things worth noting

- **Non-preemptible kernel** makes the single static `g_spawn_buf` (and the static
  argv copy store) safe: preemption fires only on a ring-3 timer tick, never mid
  syscall, so two spawns never interleave.
- **Writing to a not-yet-running stack:** the stack is demand-paged, so the kernel
  must fault the pages in itself before writing argv — done via the M14 VMA path,
  reusing exactly the same fill mechanism the #PF handler uses.
- **Race-free status:** delivering the exit code into the waiter (not reading it
  from the soon-to-be-reaped zombie) means the idle reaper and the waiter never
  fight over the zombie's lifetime.

## Deferred / next

- **envp content**: the array is set up (empty) and passed; populating a real
  environment is trivial follow-up when something needs it.
- **User-spawned children** load from a VFS path (the parent must reference a file
  in the VFS). Spawning from an embedded buffer is a kernel-only path.
- **M17** (next): blocking `SYS_SLEEP` + blocking `SYS_MSG_RECV` on the same
  block/wake primitive. Pipes + TTY are deferred until `fork`/signals (Phase G/L)
  make them worthwhile — see `docs/ROADMAP_TO_COMPLETE_OS.md`.
